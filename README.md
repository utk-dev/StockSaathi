# StockSaathi

StockSaathi is a browser-based inventory management application
designed for multi-shop pharmacies. It helps store managers monitor
stock levels, identify medicines that need reordering, recommend stock
transfers between branches, and track batches nearing expiry. 
 
## 🚀 Live Demo

**Website:** https://stock-saathi-delta.vercel.app/

## Features

-   Multi-shop inventory management
-   Intelligent reorder point calculation
-   Cross-shop stock transfer recommendations
-   Expiry tracking with alerts
-   CSV import and export
-   Sample dataset for demonstration
-   Responsive dashboard
-   Inventory summary cards
-   Batch-wise stock managemen

## Tech Stack

-   HTML5
-   CSS3
-   Vanilla JavaScript
-   Browser-based application

## How to Run

1.  Download the project.
2.  Open `index.html` in any modern browser.
3.  Load sample data or upload a CSV.
4.  Manage inventory and export results.

## Core Capabilities

-   Calculates reorder points from weekly sales.
-   Suggests transfers between Shop 1 and Shop 2.
-   Prevents unnecessary duplicate orders.
-   Tracks medicine expiry batches.
-   Displays inventory insights on an interactive dashboard.
